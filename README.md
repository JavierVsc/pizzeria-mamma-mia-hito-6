# pizzeria-mamma-mia-hito-5
Deploy Sitio: https://pizzeria-mamma-mia-hito-5.onrender.com

## Descripción

En este Hito 5, el foco principal fue implementar navegación con React Router.

Para lograrlo, se trabajó sobre la base del Hito 4 y se configuraron rutas para las distintas vistas del sitio, como Home, Login, Register, Cart, Profile, Pizza y NotFound.

Además, se trasladaron las vistas principales a una carpeta `pages` y se modificó el Navbar para navegar usando enlaces de React Router, sin recargar la página.

El sitio sigue conectado a la API de pizzas publicada en Render anteriormente.
